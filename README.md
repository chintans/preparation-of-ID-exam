# Independent Director Exam – Interactive Prep

This is your personal study repo for the **Independent Director Online Proficiency Self-Assessment Test**, run by IICA under Rule 6 of the Companies (Appointment and Qualification of Directors) Rules, 2014.

## How a session works (~30 minutes, in chat)

1. Open Claude Code in this repo and type **`/id-session`**.
2. The tutor explains 2–3 short lessons **in chat**. After each one you can ask as many follow-up questions as you like, or say **next**.
3. Say **quiz** when you're ready, or the tutor will start it after the last lesson. The questions come up as clickable multiple-choice prompts, and you get feedback after each batch.
4. The tutor commits the session record, your score, the doubts you raised, and its analysis to `main`. The next session is designed from that.

You never have to edit files yourself.

## Files (the tutor's memory)

| File / folder | What it is |
|---|---|
| `syllabus.md` | Full topic map with your status per topic |
| `progress.md` | Session log, scores, per-topic accuracy, weak areas |
| `sessions/YYYY-MM-DD/session.md` | What was taught, your doubts, quiz questions with your answers, next steps |
| `analysis/` | Progress reviews every 5 sessions and after surprise tests |
| `.tutor/state.md` | The tutor's plan and notes |
| `.claude/skills/id-session/` | The session protocol behind `/id-session` |

## Surprise tests

On a random day (never in the first 3 sessions), `/id-session` skips the lessons and goes straight into a mixed test of 15–20 questions across everything covered so far.
